# ПЕРЕЕЗД.md -- с чего начать в Claude Code

## Для автора (Даны): как запустить

1. Распакуйте архив в папку на компьютере, например «Документы / sideros-site».
2. Откройте приложение Claude, вкладку **Code**, и выберите эту папку как рабочую.
3. Убедитесь, что в Claude Code доступны подключения **Google Drive** и **Google Docs** (как в обычном чате). Если их нет -- Claude подскажет, как подключить.
4. Первым сообщением напишите:

   > Прочитай CLAUDE.md и ПЕРЕЕЗД.md. Начинаем строить настоящий сайт по прототипу.

Дальше Claude будет вести сам и спрашивать, когда нужно ваше решение или вход в аккаунт (GitHub, Porkbun). Пароли ему не нужны: входите сами, когда он попросит.

В GitHub: файл/настройка Custom domain `sideros.morphemes.space`, Enforce HTTPS; желательно подтвердить домен в настройках GitHub Pages (TXT-запись). Автор вписывает записи сама -- назвать ей точные значения или помочь через браузер.
8. **Запуск.** Правило «при запуске нет new» (CLAUDE.md, «Значок new»), запись «Сайт открылся» в Log, проверка доступности из России и с телефона, проверка печати. Простая статистика без cookies -- если ставится легко и сервис доступен из России; иначе пропустить.

Чего не делать:
- Не трогать на Диске ничего вне «!SAIT-SIDEROS».
- Не править тексты автора сверх автоматических правил (тире `--`, ёлочки, лишние пробелы) -- всё остальное только вопросами.
- Не добавлять рассылки, счётчики со слежкой, cookies-баннеры, автозапуск звука и прочий шум. Простая статистика без cookies допустима (CLAUDE.md, «Служебное на всех страницах»).
- Не переносить на сайт заглушки из прототипа (пьесы «Комната с окном на север», «Утро», проза «Вокзал», примерные альбомы и песни).
